RLS — ЗАКРЫТАЯ СТАТИСТИКА СКАЧИВАНИЙ, ВЕРСИЯ 22

БЫСТРЫЙ ЗАПУСК

1. В панели хостинга включите PHP 8.1 или новее для домена конструктора.
   На GitHub Pages PHP не выполняется; нужен PHP-хостинг.
2. Загрузите содержимое архива с сохранением структуры. В корне конструктора
   должны быть index.html, app.js, download-stats.js, папки api, private-stats
   и все прежние файлы. Загрузите также private-stats/.htaccess.
3. Папка private-stats должна быть доступна на запись пользователю PHP.
   Обычно это работает с правами папки 700 или 750 при правильном владельце.
   Если запись недоступна, исправьте владельца через панель/поддержку хостинга.
4. Откройте конструктор по HTTPS и один раз скачайте готовый макет.
5. В файловом менеджере хостинга откройте КАК ТЕКСТ файл:

   private-stats/downloads.log.php

   Он появляется автоматически при первом зарегистрированном скачивании.
   Это обычная текстовая сводка. Расширение .php защищает её от просмотра
   по веб-ссылке. Первая строка служебная, ниже — читаемый отчёт на русском.
   Внизу файла хранится служебное состояние. Не редактируйте его вручную.

ЧТО СЧИТАЕТСЯ

— Общее количество за всё время с момента установки.
— Количество за день по московскому времени (00:00–23:59:59).
— Количество за календарную неделю: понедельник — воскресенье.
— Количество за календарный месяц: с первого по последнее число.
  Длина месяца определяется автоматически, включая 28/29 февраля.
— История по каждому месяцу, неделе и дню. Промежутки без скачиваний — нули.
— Количество по типам: футбольная форма, парадный костюм, тренировочный костюм,
  ветровка и зимняя куртка.

Один готовый PNG, для которого браузеру передана команда скачивания,
считается одним событием. Ошибка подготовки PNG и простой клик по кнопке
до готовности файла не учитываются. Повторное нажатие «Скачать PNG»
для того же результата из модального окна не добавляет дубль.
Новое нажатие «Скачать макет» с новой подготовкой файла — новое событие,
даже если цвета не менялись. Это число выгрузок, а не уникальных посетителей.
Браузер не сообщает сайту, сохранил ли человек файл на диск или отменил сохранение.

Общее число никогда не сбрасывается при смене дня, недели или месяца.
Старая история сохраняется, а для нового периода начинается отдельный подсчёт.
Скачивания до установки этой версии восстановить автоматически невозможно.

ОБНОВЛЕНИЕ СВОДКИ

Файл обновляется после каждого полученного события скачивания.
В шапке всегда указаны дата и время формирования сводки: строки «за день»,
«за неделю» и «за месяц» относятся к этой дате. Если после полуночи новых
скачиваний не было, сводка останется на время последнего обновления.
Новые события автоматически попадут в правильный период без ручного сброса.

Если нужна свежая шапка даже в дни без скачиваний, настройте задание cron
в панели хостинга раз в день после полуночи ПО МОСКВЕ:

   php /полный/путь/к/конструктору/api/download-stats.php --refresh

Путь к PHP и часовую зону планировщика уточните в панели хостинга.
Команда только пересоздаёт сводку и не увеличивает число скачиваний.
Она не выводит статистику в консоль.

КОНФИДЕНЦИАЛЬНОСТЬ И НАДЁЖНОСТЬ

Счётчики не выводятся в интерфейс, консоль браузера или ответы API.
API только принимает событие и возвращает пустой ответ; просмотра итогов
по веб-ссылке нет. Обращения к серверу видны в сетевых инструментах браузера,
как любые запросы сайта, но чисел статистики в этих ответах нет.
Файл отчёта при обращении по URL отвечает 404 (или 403 на Apache).
Папка дополнительно закрыта .htaccess на Apache; защита самого PHP-файла
работает и на PHP-хостинге с nginx. Выполнение PHP должно быть включено.

IP-адреса, имена, фотографии и содержимое макетов журнал не хранит.
Передаются только тип экипировки и случайный идентификатор выгрузки.
При одновременных запросах запись блокируется, а готовый отчёт заменяется
атомарно: параллельные скачивания не затирают друг друга.
При временном сбое соединения события повторно отправляются из браузера.
Очередь ограничена 100 событиями и 48 часами. Если посетитель не вернётся
или очистит данные браузера до отправки, событие может не дойти.
Дата учёта — время получения события сервером (в Москве).
Повторная доставка того же события в течение 7 дней не увеличивает счётчик.
Сбой статистики не блокирует сохранение PNG.

ОБНОВЛЕНИЯ И РЕЗЕРВНАЯ КОПИЯ

Не удаляйте и не заменяйте private-stats/downloads.log.php при обновлении сайта.
Этот файл не включён в чистый архив: ваша история сохраняется на хостинге.
Для резервной копии скачайте этот один файл через панель хостинга/SFTP.
Скрытый файл .write.lock используется только для блокировки записи.
При повреждении существующего журнала обработчик не обнуляет историю:
он сохраняет исходный файл и записывает ошибку в стандартный журнал PHP хостинга.

При желании хранить отчёт вне публичной папки сайта измените параметр
directory в api/stats-config.php на абсолютный путь к закрытой папке.
Она должна быть доступна пользователю PHP на запись.
Часовая зона задаётся в том же файле (по умолчанию Europe/Moscow).
